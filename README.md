I implemented a CGCNN in PyTorch Geometric to predict molecular energy and tested whether using rotation-invariant edge features (interatomic distances) helps compared with raw distance vectors. With identical settings, the invariant model reached a test MAE of 0.144 against 0.168 for the vector-edge model, and its predictions do not change when the molecule is rotated, which I checked directly. Results are from a single run per model, so the gap should be confirmed with several seeds.
